# Strong Input Buffer

A configurable early-jump buffer for Geometry Dash on Windows. It keeps vanilla clicks immediate, then replays an already-released early tap when you reach the ground or an orb within the chosen timing window.

**Features**: adjustable 0–250 ms window, orb support, separate P1 and P2 state, automatic cleanup on death/restart/checkpoint. Ship/UFO/wave/swing controls are not modified.

**Note**: Input assist; use for practice and casual play. Very large windows can cause unintended jumps.
